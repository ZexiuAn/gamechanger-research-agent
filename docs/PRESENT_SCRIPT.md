# 易动调研助手 · 演示话术（约 90 秒）

## 开场（15s）
「这是北京易动纷享科技有限责任公司 R&D 场景下的**易动调研助手**。起点不是做万能 Agent，而是先解决研发同学的**竞品/技术调研简报**：检索、归纳、落盘。」

## 主 Demo（45s）
1. 打开 Web UI，点左侧「竞品 / 技术调研简报」  
2. 勾选「思考轨迹」，发送  
3. 指出：多步工具调用（research_kb / MCP → web_search → fetch_url → 落盘 → terminate）  
4. 结束后展示**面向用户的调研结论**，并打开 `workspace/research_brief_*.md`  

## 泛化（20s）
「闭环跑通后，同一套编排也能做文档整理。」点「内部文档任务整理」，说明这是**可复用原型机**，不是一次性脚本。

## 收尾（10s）
「和知识库 RAG 项目互补：RAG 深挖固定文档，Agent 对外办事并产出文件；业务工具还可通过 MCP 标准接口热插拔。」
